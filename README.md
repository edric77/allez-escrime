# Allez

PWA d’organisation de tournois d’escrime multi-clubs.

## Voir en local

```bash
python3 -m http.server 4173
```

Ouvrir http://127.0.0.1:4173

## Déployer sur Vercel

1. Aller sur https://vercel.com/new
2. Importer `edric77/allez-escrime`
3. Framework preset : **Other**
4. Deploy

Site statique, pas de build.
